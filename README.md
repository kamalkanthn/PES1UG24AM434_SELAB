# Podcast Guest Scheduling & Outline Builder

## Software Engineering Lab 1

**Problem Statement #60**

This project is a podcast management system that helps hosts schedule guests and prepare podcast episodes.

### Main Features

* Guest can view and book interview slots.
* Host can add and manage available slots.
* Guest can submit topic outlines and biography links.
* System sends calendar invites.
* Guests can cancel or reschedule bookings.
* System generates a run-of-show production sheet.

### Actors

* Podcast Guest
* Show Host
* Calendar/Notification System

### Requirements

* 5 Functional Requirements
* 2 Non-Functional Requirements
* UML Use-Case Diagram
* Use-Case Flow Specification

### Core Use Case

**Book Interview Slot**

The guest selects an available slot, confirms the details, and books the interview. The system sends a calendar invite and adds the booking to the production board.
